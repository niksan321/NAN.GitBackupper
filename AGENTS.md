# Инструкции для агентов (Cursor)

## Проекты C#

- Во всех `.csproj` используйте **`<Nullable>disable</Nullable>`** (отключённый контекст nullable-ссылок), чтобы согласовать поведение компилятора с существующим кодом без массовых правок аннотаций.

Не включайте `<Nullable>enable</Nullable>` в новых проектах репозитория без явного запроса.

## WPF и тема (Material Design)

- Старайтесь опираться на **ресурсы темы** (`DynamicResource` / `StaticResource` для кистей и стилей из Material Design и проекта [`NAN.MaterialDesignThemes.Orange`](Src/NAN.MaterialDesignThemes.Orange/Themes/OrangeDarkTheme.xaml)), например `MaterialDesign.Brush.Foreground`, `MaterialDesign.Brush.Primary`, `MaterialDesign.Brush.Card.Background` и готовые стили контролов.
- **Не задавайте произвольные цвета** контролам (`Foreground`, `Background`, `BorderBrush` и т.п. через жёстко прописанные `#RRGGBB` / именованные цвета), если нет явной необходимости или просьбы пользователя — иначе элементы перестают согласовываться с тёмной темой и палитрой приложения.

## Git: команда «коммить» = коммит, затем pull, затем push

По команде пользователя **«коммить»** агент выполняет **полную синхронизацию** в строгом порядке — **не останавливайтесь после одного только коммита**:

1. **Коммит** — `git add` при необходимости, затем `git commit`. Сообщение **на русском**, кратко по делу, без заглушек вроде «update».
2. **`git pull`** — подтянуть изменения с remote для текущей ветки (**обычное слияние**, не rebase).
3. **`git push`** — отправить ветку на remote.

**Нельзя** для этого сценария использовать **`git rebase`**, **`git pull --rebase`** и переписывание истории через rebase (если пользователь не попросил явно).

Если пользователь сказал **«только коммит»** / **без push** — выполняйте только шаг 1.

Если **pull** или **push** невозможны (конфликты после pull, нет remote, нет доступа, пользователь запретил синхронизацию) — сообщите пользователю, не скрывайте ошибки и не подделывайте успех.

Подробнее то же правило в [`.cursor/rules/git-commit-sync.mdc`](.cursor/rules/git-commit-sync.mdc) (`alwaysApply`).
